GOPASAL TESTER FOR WINDOWS
==========================

FIRST TIME
1. Install Docker Desktop for Windows:
   https://www.docker.com/products/docker-desktop/
2. Restart Windows if Docker asks you to.
3. Open Docker Desktop and wait until it says the engine is running.
4. Double-click Start-GoPasal.cmd.

The first start downloads the platform from GoPasal's public GitHub container
packages and can take several minutes. No GitHub login is required. Later starts
are much faster. A browser page opens when every service is ready.

EVERYDAY USE
- Start-GoPasal.cmd: starts GoPasal and checks for a tested update.
- Stop-GoPasal.cmd: stops it without deleting test data.
- Update-GoPasal.cmd: explicitly downloads and starts the newest tested build.
- Export-Diagnostics.cmd: creates a ZIP to privately send to the developer.
- Reset-Test-Data.cmd: permanently removes local test data and starts fresh on
  the next launch. It requires typing RESET so it cannot happen accidentally.

IMPORTANT
- Keep Docker Desktop running while testing.
- Do not share the generated .env file. It contains local session secrets.
- This package binds every port to 127.0.0.1. Other computers cannot open it.
- Online payments and real SMS are intentionally unavailable without provider
  credentials. Cash on delivery and the genuine OTP verification workflow work.
- Exported diagnostics can contain test personal data and OTP log lines. Share
  the ZIP only with the GoPasal developer through a private channel.
